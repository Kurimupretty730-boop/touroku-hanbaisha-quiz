登録販売者 6年720問 Webアプリ

今回の主な修正
- 上部カウンターを「回答済／正解／弱点」の3つに整理
- 不正解・「わからない」は自動で弱点、正解時は既定で弱点解除
- 回答後に「✓ 正解」「★ 弱点」を選べ、勘で当たった問題も弱点に残せる
- 次の問題へ進むたびに画面上部へ自動スクロール
- 問題画面に「一覧」を追加。任意の問題へジャンプ可能
- 一覧は ○=正解、×=不正解・わからない、白=未回答
- 通常／平行／テスト／復習で保存確認を行い、保存データは複数保持
- 終了確認は「保存して戻る／保存せず戻る／問題に戻る」の3択
- 弱点復習では「次へ」で次の弱点問題へ進む
- 全問回答後は正解数・正答率を表示。単年度120問では合格基準も表示
