## 解説統合（令和元〜6年度）
令和元〜6年度の720問すべてについて、ユーザー提供の「問題・回答・解説」テキストから解説を統合済みです。

照合条件:
- 年度
- 章の並び（元テキストの第1章→第2章→第3章→第4章→第5章の順を、アプリの午前/午後IDへ対応）
- 章内の問番号
- 問題見出し
- 回答番号
- アプリ内公式解答キー

回答番号が1つでも一致しない場合は統合処理を停止する条件で実行。
最終結果: 720/720問でアプリ正答と公式解答キーが一致、解説720/720問を対応付け済み。

## 今回の更新（保存操作）
- 問題画面に「💾 保存」ボタンを追加しました。保存後も同じ問題画面に残り、そのまま学習を続けられます。
- 新規学習を最初に保存すると保存枠が1件作られ、同じ学習中に再度「保存」するとその保存枠を上書きします。
- 「保存した学習」から再開したデータを再保存した場合も、別データを増やさず元の保存枠を上書きします。

## 2026-09-29 fresh-start / reset update
- 通常学習・平行モード・テストモードをホームの学習モードから開始した場合は、過去の回答履歴や以前の位置に関係なく先頭から開始します。
- 続き位置は明示的に「保存」した学習だけが保持します。同じ保存データから再開して保存した場合は上書きします。
- 新しく学習モードから開始したセッションを保存すると、以前の保存とは別の保存データになります。
- 過去の○×回答履歴は消さず、問題画面右上の履歴表示に利用します。
- 漢方暗記・生薬暗記に「記録をリセット」を追加しました。「今の状態を保存してリセット」を選ぶと、現在の○×をホームの「保存した学習」に退避してから現行記録を空にします。
- 退避した漢方・生薬記録はホームの「保存した学習」から再開でき、再保存はその保存記録を上書きします。
