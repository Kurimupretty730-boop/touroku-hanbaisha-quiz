# 登録販売者 午後200問 Webアプリ

- 令和元年度〜令和5年度の「午後」問1〜40、計200問
- 問題文は提供された公式試験問題PDFから抽出
- 正答は公式解答PDFで確認済みの午後解答を使用
- 初見正解は定着。間違い/「わからない」は弱点として保存し、その後2回連続正解で定着
- 端末内保存（localStorage）
- JSON書き出し/読み込みでスマホ⇄PCの進捗移行可能
- HTTPSで公開するとPWAとしてホーム画面追加・オフライン利用が可能

## 公開
このフォルダ一式を GitHub Pages / Netlify / Cloudflare Pages 等の静的ホスティングへアップロードしてください。
`index.html` が入口です。
