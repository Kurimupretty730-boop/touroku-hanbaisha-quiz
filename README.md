# 登録販売者 6年720問 Webアプリ

令和元〜6年度、各120問、計720問。

- 問題文・選択肢：アップロードされた公式問題PDFから抽出
- 正答：各年度の公式解答PDFから抽出し、アプリ起動時にも正答キー照合
- 通常学習：年度・章ごとに進捗位置を個別保存
- 平行モード：同じ章内問題番号をR1→R6の順で比較
- テストモード：年度別120問、本番順。総合70%以上かつ各章40%以上で判定
- 弱点 / 定着 / 未定着の手動指定
- 保存した学習は明示的に保存した平行モード・テストのみ

※ 現版は公式問題・正答データと学習機能を先に収録。35189.jpの解説は著作権上そのまま転載せず、意味を保った要約として後続版に追加予定。


## 解説統合版
- 720問すべてに、公式問題・公式正答から作成した短い正答根拠を表示します。
- 各問題の解説欄から、対応する35189.jpの年度・章ページを1タップで開けます。
- 第三者サイトの解説文は大量転載せず、アプリ内文は独自の要約です。
