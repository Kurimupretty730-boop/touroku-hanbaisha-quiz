# 登録販売者 6年720問 Webアプリ

令和元〜6年度の公式問題PDF・公式解答PDFを基にした学習用Webアプリです。

## 今回の修正
- 章順：1 → 2 → 4 → 3 → 5
- 問題本文と a/b/c/d 等の記述を自動改行
- 問題文末に連結していた選択肢を720問すべて分離表示
- 選択肢本文は比較用にコンパクト表示し、回答ボタンは①〜⑤（4択問題は①〜④）を横並び
- 弱点／未定着などの一覧から開いた場合、「次へ」で同じ一覧の次問題へ進む
- 通常学習・平行モード・テスト・復習を複数個「保存した学習」に保存可能
- 終了時は「保存して戻る／保存せず戻る／問題に戻る」の3択
- 上部の回答済／正解／弱点／定着カウンターを押して対応一覧へ移動可能。学習中は保存確認を表示

進捗はブラウザの localStorage に保存されます。
